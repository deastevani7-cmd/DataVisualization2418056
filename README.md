# DataVisualization2418056

# Deskripsi

Proyek ini bertujuan untuk melakukan visualisasi data karyawan menggunakan Python dan Google Colab. Visualisasi dibuat dalam bentuk grafik batang (bar chart) untuk mempermudah pemahaman mengenai distribusi karyawan berdasarkan beberapa kategori.

# Tujuan
1. Mengetahui distribusi peran pekerjaan karyawan.
2. Mengetahui jumlah karyawan berdasarkan jenis kelamin.
3. Melihat distribusi status attrition (karyawan keluar atau bertahan).
4. Mengetahui jumlah karyawan berdasarkan status lembur.
5. Melihat distribusi perjalanan bisnis karyawan.
6. Mengetahui jumlah karyawan pada setiap departemen.
7. Menganalisis distribusi status pernikahan dan kepuasan kerja.

# Tools dan Library
1. Python
2. Google Colab
3. Pandas
4. NumPy
5. Matplotlib

# Tahapan Pengerjaan
1. Mengimpor library yang diperlukan.
2. Memuat dan menampilkan dataset.
3. Mengidentifikasi nama kolom yang digunakan.
4. Menghitung jumlah data pada setiap kategori.
5. Membuat visualisasi grafik batang secara terpisah untuk setiap kolom.
6. Menampilkan judul, label sumbu, grid, dan nilai pada setiap batang grafik.

# Visualisasi
Visualisasi yang dibuat meliputi:
1. Distribusi Peran Pekerjaan (Job Role).
2. Distribusi Jenis Kelamin (Gender).
3. Distribusi Status Attrition (Attrition).
4. Distribusi Lembur (OverTime).
5. Distribusi Perjalanan Bisnis (Business Travel).
6. Distribusi Karyawan Berdasarkan Departemen (Department).
7. Distribusi Status Pernikahan (Marital Status).
8. Distribusi Kepuasan Kerja (Job Satisfaction).

# Hasil
Hasil visualisasi membantu menggambarkan distribusi karyawan berdasarkan kategori yang tersedia dalam dataset. Grafik dapat digunakan untuk membandingkan jumlah karyawan pada setiap kategori dan menjadi dasar analisis lebih lanjut mengenai kondisi sumber daya manusia di perusahaan.

# Kesimpulan
Berdasarkan hasil visualisasi, grafik batang membantu memahami distribusi karyawan berdasarkan delapan variabel, seperti peran pekerjaan, jenis kelamin, attrition, lembur, departemen, dan kepuasan kerja. Visualisasi ini memudahkan perbandingan jumlah karyawan pada setiap kategori serta dapat menjadi dasar evaluasi dan pengambilan keputusan dalam pengelolaan sumber daya manusia.
